\section{Experimental Protocol and Results}
All experiments are generated by scripts in \texttt{benchmarks/}. Synthetic traces use fixed random seeds. The real-data protocol uses FDSN query URLs recorded in the data manifest, including the 2019 Ridgecrest strong-motion interval. Comparator points are loaded only from successful executable runs; the plotting script marks SZ3 as unavailable rather than synthesizing a result when the official binary is absent. Timing summaries use medians, and rate--distortion error bars report standard errors across five deterministic traces.

Physical fidelity is evaluated independently of sample-domain MSE. Welch spectra use a 1024-point Hann window with 50\% overlap. Log-spectral distance integrates the squared decibel PSD ratio after applying a $10^{-12}$ floor. Arrival jitter is the maximizing lag of overlap-normalized cross-correlation. Peak acceleration error is the maximum absolute error among the top 1\% of source magnitudes. The artifact test requires zero maximizing lag for the deterministic arrival trace and verifies a rate-matched uniform-quantizer LSD gap of at least 3~dB on the declared resonance experiment; the real Ridgecrest value is reported without substituting the synthetic criterion.

Random-access scaling uses a cached \texttt{IndexedStreamView}, a centered 512-sample query, and arrays from $10^3$ through $10^7$ samples. The linear baseline performs full-frame decompression; it is not an extrapolated line. This distinction makes the asymptotic comparison reproducible while retaining absolute latency measurements.

The theoretical-slack report decomposes actual rate into the normalized GED Shannon bound, fixed framing, the conservative $K/(4096\ln2)$ rANS frequency-quantization bound, and a signed residual remainder. A signed remainder is retained deliberately: clipping it would conceal finite-sample or source-model violations. Reproduction commands, software versions, counter diagnostics, and generated vector PDFs constitute the publication artifact.
